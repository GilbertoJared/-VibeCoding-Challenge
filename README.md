# 🏹 Chronos Shooter: Cavernícola Rush

**Chronos Shooter: Cavernícola Rush** es un top-down shooter 2D desarrollado en HTML5 Canvas y JavaScript para el **VibeCoding Challenge**.

---

## 📜 Historia del Juego
Un científico que realizaba pruebas con un dispositivo de viaje en el tiempo sufre un fallo en el núcleo, quedando atrapado en una falla del espacio-tiempo. Para reparar el portal y regresar al presente, debe sobrevivir a hordas de cavernícolas mutantes a través de **2 Mundos** (*Era de Piedra Mutante* y *Falla Temporal Futura*), enfrentando **5 niveles de dificultad progresiva** por cada mundo.

---

## 💻 Plataforma e Instalación

El juego está desarrollado para ejecutarse de forma nativa en **navegadores web para PC** (Google Chrome, Mozilla Firefox, Microsoft Edge) sin necesidad de instalar servidores ni dependencias externas.
